## Genomics & Sequencing

Tools and platforms for DNA/RNA sequencing and genomic analysis.

- [Illumina](https://www.illumina.com/) — Sequencing technology and genomic analysis platforms.
- [Oxford Nanopore](https://nanoporetech.com/) — Long-read sequencing technology for real-time DNA/RNA analysis.
- [BWA](http://bio-bwa.sourceforge.net/) — Burrows-Wheeler Aligner for mapping low-divergent sequences.
- [Bowtie](http://bowtie-bio.sourceforge.net/index.shtml) — Fast aligner for short DNA sequence reads.

## Proteomics & Structural Biology

Tools and platforms for analyzing proteins, structures, and molecular interactions.

- [AlphaFold](https://alphafold.ebi.ac.uk/) — AI system for predicting protein structures.
- [PyMOL](https://pymol.org/) — Molecular visualization system for 3D structures.
- [UniProt](https://www.uniprot.org/) — Comprehensive resource for protein sequence and annotation data.

## Bioinformatics Tools & Libraries

Libraries and frameworks for computational biology and bioinformatics workflows.

- [Bioconductor](https://www.bioconductor.org/) — R-based project for genomic data analysis.
- [BioPython](https://biopython.org/) — Python library for biological computation.
- [BioJulia](https://biojulia.net/) — Julia-based ecosystem for bioinformatics tools.

## Data Analysis & Visualization

Tools for analyzing, visualizing, and interpreting biological data.

- [Galaxy](https://usegalaxy.org/) — Web-based platform for accessible bioinformatics analysis.
- [IGV (Integrative Genomics Viewer)](https://software.broadinstitute.org/software/igv/) — Visualization tool for genomic data.
- [Plotly](https://plotly.com/) — Data visualization library used in bioinformatics workflows.

## Databases & Repositories

Repositories and datasets for genomic, proteomic, and biological data.

- [NCBI](https://www.ncbi.nlm.nih.gov/) — National Center for Biotechnology Information database resources.
- [Ensembl](https://www.ensembl.org/) — Genome database for vertebrates and other species.
- [PDB (Protein Data Bank)](https://www.rcsb.org/) — Repository for 3D structural data of proteins and nucleic acids.

## Workflows & Pipelines

Tools for building, managing, and automating bioinformatics workflows.

- [Nextflow](https://www.nextflow.io/) — Workflow management system for scalable bioinformatics pipelines.
- [Snakemake](https://snakemake.readthedocs.io/) — Workflow engine for reproducible data analysis.
- [Cromwell (WDL)](https://cromwell.readthedocs.io/) — Workflow execution engine for genomic pipelines.

## Education & Resources

Learning resources, tutorials, and educational platforms for bioinformatics.

- [Coursera Bioinformatics Specialization](https://www.coursera.org/specializations/bioinformatics) — Structured online courses in bioinformatics.
- [edX Bioinformatics Courses](https://www.edx.org/learn/bioinformatics) — University-level courses in bioinformatics.
- [Rosalind](https://rosalind.info/) — Platform for learning bioinformatics through problem-solving.
